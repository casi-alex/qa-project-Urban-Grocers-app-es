# Proyecto Urban Grocers 
## Pruebas para el parámetro "name" al crear un kit
- Necesitas tener instalados los paquetes pytest y request para ejecutar las pruebas.
- Ejecuta todas las pruebas con el comando pytest.
## Fuente de documentación utilizada
Se utilizó **https://cnt-33a1f380-89ee-434d-a2ec-bdc91d44ec9b.containerhub.tripleten-services.com/docs/** como fuente de documentación de la API de Urban Grocers. La documentación se accedió a través de [URL_BASE]/docs/ y proporcionó informacion sobre:
- Endpoints disponibles
- Estructura de las solicitudes
- Parámetros requeridos y opcionales
- Formatos de respuesta esperados
- Códigos de estado HTTP
## Tecnologías y técnicas utilizadas
- Se hicieron pruebas automatizadas usando **Pytest** a través de **Pycharm** usando diferentes tipos de datos de **Python** como **números, strings, listas, tuplas**, así como el uso de **bucles**, **funciones** y el comando **assert**
- Asimismo se usó la librería **requests** para realizar **solicitudes GET y POST** en base a la lista de comprobación
- Finalmente se creó un **repositorio de GitHub** con **autenticación SSH** el cual se vinculó a otro **repositorio remoto** usando el comando **push**
